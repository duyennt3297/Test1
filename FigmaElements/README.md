# FigmaElements

Thư mục này chứa các thành phần thiết kế cho dự án.

Cấu trúc gợi ý:
- FigmaElements/
  - canonicals/    # canonical components and rules
  - components/    # component exports and prototypes
  - assets/        # exported assets (SVG, PNG)
  - tokens/        # design tokens (JSON/CSS variables)

Bạn có thể thêm các file thiết kế hoặc thư mục con như `assets/`, `tokens/`, `components/` vào đây.
